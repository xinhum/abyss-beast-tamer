# 深渊驯兽师 · 单机 Roguelike 爬塔 + 宠物捕获

一个**单机 Roguelike 卡牌爬塔**原型：带一只宠爬塔，靠战斗赚唯一货币「灵魂值（SL）」，在荒野抓宠、在商店买补给、在祭坛赌强化。抓到的宠**局内不升级、局终不保留**，每局战力全靠「选择」。

本项目包含完整的**策划案 → 数值配表 → 可玩 Demo → 仿真验证**闭环，用于展示系统设计与数值落地的能力。

## 二、核心设计

### 核心循环

```
战斗 → 获得 SL → 节点二选一 → 消费（抓宠 / 买补给 / 赌事件）→ 回到战斗
```

每 8 层为一个阶段，阶段末为 Boss。**唯一货币 SL 总量刻意压紧**——到每个关键节点前，只够做一次大额抉择。

### 三套系统

| 系统 | 规则要点 | 设计意图 |
|---|---|---|
| **SL 经济** | 全游戏只有一种钱；捕获、商店、换宠全部消耗它；卖宠回收 40% | 单货币 + 强约束，制造「抓宠 or 存活」的零和博弈 |
| **捕获** | 战斗中留活口 → 战后 10 秒一口价；价格 = 基准 × 词条 × 同属性 × 路线；队伍满可替换 | 把「抓宠」做成局内经济下注，而非抽卡 |
| **战斗** | 每回合 1 个行动：普攻 / 技能 / 指令；大招只能由「命令·大招」引爆；五系克制 | 宠物是引擎，卡牌是放大器 |

### 五系克制

`火 → 草 → 水 → 火` 循环克制；`暗 ⇄ 光` 双向互克；暗光不与三系发生关系。

### 节点系统（替代传统三路线）

| 节点 | 权重 | 说明 |
|---|---|---|
| 普通战 | 54 | 标准收益（+55 SL） |
| 精英战 | 32 | 敌人 ×1.4，收益 +85 SL，捕获品质 +1 档 |
| 回血祭坛 | 5 | 回复 40% 生命 |
| 黑市商店 | 4 | 只卖增益（强化 / 护盾 / 捕获网），**不回血** |
| 事件 | 5 | 遗弃巢穴 / 强化台 / 试炼之柱 |

- 每层随机 2 个节点，玩家二选一。
- **特殊节点动态概率（pity）**：基础 5%/节点，每层未出现 +4%，上限 35%，出现即重置。
- **Boss 前一层硬保底**：固定「回血祭坛 / 黑市商店」二选一。

## 三、数值体系

| 参数 | 数值 |
|---|---|
| 单局层数 | 3 段 × 8 层 = 24 层（Boss 在 8 / 16 / 24） |
| 敌人分段基座 | 1.0 / 1.4 / 1.9（段内 ×1.09^层序） |
| 宠物品质系数 | 白 1.0 / 蓝 1.25 / 紫 1.6 / 橙 2.1 |
| 战斗内成长 | Boss 后全局 +8%（伤害与最大生命）、换段词条 +12%（三选一）、事件 +8% |
| 击杀成长 | **不做**（避免不可控膨胀） |
| 敌人数 | 普通层 2–4 只；Boss 层 1 只 |
| 词条 | 暴击 +12% / 受击减伤 8% / 每场 SL +6 / 大招 CD −1 |

**设计红线**：局外不保留任何实体（宠物、SL、道具），只解锁球种、词条池、起始牌与难度阶。

## 五、验证方法

| 层次 | 方法 | 状态 |
|---|---|---|
| 静态校验 | 概率归一、资源守恒、单调性、边界取整、克制矩阵 | 已做（配表「验证自检」页，13 项全 PASS） |
| 数值仿真 | 固定种子蒙特卡洛，输出 TTK 分布与通关率 | 已做（`tools/` 下的仿真脚本） |
| 真人可玩性 | 首体验、留活口是否看懂、捕获压力、卡点归因 | **待做** |

**仿真局限（重要）**：当前仿真为「伤害竞速」简化模型，未建模技能 CD 轮转、暴击、治疗、索敌与走位，因此**可信的是 TTK 方向，不能直接给出真人通过率**。通过率与手感必须真人测试。

## 六、已知缺口（诚实清单）

1. Web Demo 目前只实现**一段 8 层 + 1 个 Boss**（垂直切片），24 层完整结构尚未落到 Demo。
2. 3 个 Boss 只实现了「深渊看门人」的蓄力打断机制，另两个为占位。
3. 24 层完整仿真发现**结构性缺口**：宠物血量跨段累积、补给不足，通关率极低——成长方案（Boss 后强化 + 换段词条 + 事件成长）正在验证中。
4. 无美术资源，UI 为线框级；无出手动画（音效已用 Web Audio 合成）。
5. 手机端可打开，但布局按 PC 宽屏设计。
